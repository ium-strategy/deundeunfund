관리자 대시보드 설정이 필요합니다

이 페이지는 GA4(Google Analytics 4) 데이터를 불러오도록 설정하기 전까지 실제 방문 데이터를 표시하지 않습니다. 아래 3단계를 완료한 뒤 admin.html 상단의 CONFIG 값을 채워주세요.

  1. 1

    GA4 속성 ID 확인

    GA4 관리(Admin) → 속성 설정 상단의 숫자를 GA4_PROPERTY_ID에 입력하세요. 측정 ID(G-38RPQSW8WG)와는 다른 값입니다.

  2. 2

    OAuth 클라이언트 ID 발급

    Google Cloud Console → API 및 서비스 → 사용자 인증 정보에서 "웹 애플리케이션" 유형으로 발급 후 OAUTH_CLIENT_ID에 입력하세요.

    • 승인된 자바스크립트 원본에 https://safehome.warmfund.net 및 https://ium-strategy.github.io 추가
    • "Google Analytics Data API" 사용 설정
    • OAuth 동의 화면에 관리자 이메일을 테스트 사용자로 등록
    • 스코프: https://www.googleapis.com/auth/analytics.readonly
  3. 3

    저장 후 재배포

    두 값을 저장하고 admin.html을 다시 push하면 이 안내 대신 로그인 화면이 표시됩니다.
